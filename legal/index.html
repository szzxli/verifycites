    03 Immigration guide

    Job: see where each immigration citation type is routed, and which official page to open.

    An immigration brief mixes federal court cases, BIA precedent (Matter of), INA provisions, and 8 CFR provisions. This page classifies each extracted row and names its source line; immigration rows are not yet looked up live.

    Not yet covered: no live BIA lookup in this page (8 CFR rows are matched against a static eCFR Title 8 index and INA / 8 U.S.C. rows are matched against a partial INA↔8 U.S.C. mapping table built from OLRC Title 8 — see the row's source line; unmapped sections still cannot be confirmed); no judgment on whether a case supports your argument or is still good law. A BIA precedent can be overruled, and circuit precedent controls; some Title 8 provisions may be enjoined, so eCFR text alone never proves a provision is currently in effect. The core statute and regulation text (INA, 8 CFR) changes rarely; what changes more often is policy guidance and new BIA precedent.

    Memo-currency rule: a memo's currency is shown only when the official source itself states supersession, rescission, or replacement — never inferred from list presence or absence.

    Check by hand at the official sources:

    • EOIR Agency Decisions (BIA precedent volumes)
    • EOIR Virtual Law Library (recent decisions)
    • USCIS AAO non-precedent decisions search
    • USCIS Policy Manual
    • eCFR Title 8 (Aliens and Nationality)
    • U.S. Code title 8 section
