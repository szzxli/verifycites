§1

How to export from Zotero

There is no Zotero plugin yet. Export a BibTeX file, or copy the bibliography, and check it on the /papers page.

Export a BibTeX file — the most reliable path, because the checker reads every entry:

  1. In Zotero, choose what to export: the whole library (File → Export Library…), one collection (right-click the collection → Export Collection…), or specific items (select them, right-click → Export Items…).
  2. Set the format to BibTeX and save the .bib file.
  3. Open the /papers checker. Use Upload .docx / .pdf / .bib, or paste the file's contents into the text box, then click Check citations.

Or copy the bibliography and paste it as plain text:

  1. Select the items in Zotero, then right-click and choose Create Bibliography from Item(s)… (or use Edit → Copy Bibliography).
  2. Copy to the clipboard and paste into the /papers text box, then click Check citations.

The checker accepts a pasted draft (markdown or plain text), an uploaded .docx or .pdf, or a pasted or uploaded BibTeX .bib file. It does not accept other bibliography file types as uploads.

§2

What this checks

For each citation, the checker looks up:

  • whether the citation can be found as an existing record in public registries (Crossref, DataCite/arXiv, OpenAlex, Europe PMC, DBLP; Semantic Scholar as a last resort);
  • whether a DOI or other identifier in the entry resolves and matches that record;
  • whether the paper is retracted.

A BibTeX file has no claims, so when you upload or paste a .bib the checker reports existence and identifier results only. Your draft or library file stays in your browser. Only citation identifiers and reference text are sent to the registries.

§3

What this does not check

  • It does not compare title, author, or year fields field by field. That comparison is not available yet. An author mismatch is flagged only when the check detects one.
  • It does not check whether a source supports a claim. Finding a record, or a DOI that resolves, does not mean the source supports something you wrote. If you paste a full draft instead of a .bib, an optional screen can compare a claim with the cited paper's abstract only. It does not read the full text and is not a substitute for reading the source.

“Not found” is not proof that a work does not exist. A real paper can be missing from the free indexes. Use the results to decide which references to open and check by hand.
