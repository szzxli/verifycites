About VerifyCites

VerifyCites is a set of free, open-source citation tools built by founder David Lee.

  • Legal, for U.S. lawyers, paralegals and law-school writing courses: paste a brief and get a checklist of the citations it contains, each marked NOT_CHECKED, with links to official sources so you can check each one yourself. The browser tool extracts citations only; it does not check whether a cited case exists. It also has a search of BIA precedent decisions (currently volume 30) and a hand-maintained table of selected federal court orders on AI use in filings.
  • Papers, for researchers (formerly veripaper): checks whether each cited paper exists in public registries, whether the identifier matches the record, whether it is retracted, and, as a first-pass screen, whether the cited abstract supports the claim.

Why we build it

A citation that exists does not by itself support an argument, and a citation that is missing from a database is not necessarily wrong. Where a tool checks existence, details match or claim support, VerifyCites shows each as a separate result. Every tool says what it does not check, and the final review is yours. VerifyCites is not a law firm and does not provide legal advice.

How your data is handled

  • Legal: citation extraction runs in your browser. The browser tool does not send your text to CourtListener. BIA precedent search runs in your browser against a static snapshot of the EOIR volume pages; your keywords are not sent anywhere and are not saved. Your review marks are stored in this browser only (localStorage). There is no hosted link for your brief, and nothing is stored on a server.
  • Papers: your draft text stays in your browser (.docx and .pdf text is extracted there). Only citation identifiers and reference text are sent to public registries (Crossref, DataCite/arXiv, OpenAlex, Europe PMC, DBLP, Semantic Scholar). The default keyless claim check runs a small model in your browser and sends no claims anywhere. Claims and abstracts go to OpenRouter only if you add your own key.
  • Analytics (GoatCounter): We record page views and anonymous usage events (for example, that Extract was clicked). Events carry only a fixed name, never what you paste.
  • Source: the code for this site is open source under the MIT license, so you can read how it works: github.com/szzxli/verifycites.
